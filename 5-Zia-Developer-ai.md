# Zia Developer AI 
*A beginner-friendly guide to the AI build partner (in development)*

Source: [The AI Agent Factory](agentfactory.panaversity.org/docs/ecosystem/zia-developer-ai)

---

## 1. What it is
Zia Developer AI is the builder's counterpart to Zia Tutor AI. It's a plugin for a coding agent, Claude Code or OpenCode.

You describe a business problem in plain language. Instead of guessing, it hands back an actual **decision**: which mode, which architecture shape — grounded in the book. Then it writes the spec and builds a working agent to that spec. You verify it and ship it.

> **Status:** still in development, unlike the SoR and Zia Tutor AI, which are already live.

---

## 2. Decides, then builds

It runs the book's decision gates to pick the right architecture, explains why, writes the spec, and scaffolds a real, deployable agent — not just a rough skeleton.

---

## 3. Never guesses at a gate

If your requirements don't settle a decision, it asks **one sharp question** and waits — rather than picking something and hoping for the best. This is the same spec-driven discipline the book teaches elsewhere, now applied to the architecture choice itself.

---

## 4. Lives in tools you already use

Installs into Claude Code or OpenCode in one command from a marketplace. The decision-making knowledge is a portable skill, so it works even on cheaper, economy-tier models.

---

## 5. Grounded in the same source

It reads the exact same System of Record as Zia Tutor AI — same trustworthy well, different host (a builder instead of a teacher). It fails closed rather than inventing an architecture it can't actually cite from the book.

---

## 6. The rhythm it enforces: 10-80-10, applied to building

| Step | Who does it | % of the work |
|---|---|---|
| Set the architecture decision + write the spec | Zia Developer AI | First 10% |
| Actually build it | Your coding agent | Middle 80% |
| Verify it before shipping | You | Final 10% |

It's the mirror of Zia Tutor AI: same governed source, different host. The tutor teaches the method; the developer makes it run.

---

## 7. Why it matters for your own future business

Zia Developer AI is the **reference domain builder** — Layer 2's building slot in the FDE AF Model. Every vertical you eventually build (your own profession's SoR) preloads its own version of this, with that profession's architectures and compliance rules baked in so whatever agents it produces automatically respect that profession's rules.
